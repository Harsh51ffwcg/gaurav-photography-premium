# Gaurav Photography Studio — Premium Website

A premium, responsive Next.js website concept for Gaurav Photography Studio, Indirapuram, Ghaziabad.

## Run locally
1. Install Node.js 20+.
2. Extract the ZIP and open this folder in VS Code.
3. Open Terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Visit http://localhost:3000

## Before publishing
- Portfolio images currently use Unsplash sample imagery. Replace these with the studio's actual photos before presenting this as a finished client website. The current demo does not claim sample photos are the studio's own work.
- Confirm the contact number and address with the studio before launch. Current contact details were taken from its existing public site.
- The “since 2011” line is based on a business post stating 15 years of experience in 2021; confirm before publishing or remove if not verified.
- Review quotes are shortened excerpts from reviews displayed on the existing business website. Recheck permission and wording before production use.
- Add the studio's real Instagram URL if desired.
- Images are loaded from Unsplash and require an internet connection.

## Stack
Next.js 15, React 19, TypeScript, Tailwind CSS 4, Framer Motion, Lucide icons.
